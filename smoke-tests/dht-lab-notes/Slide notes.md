## 场景 1｜Gut Health（肠道健康）

### Target User
- 普通消费者
- 亚健康人群
- 肠道不适但不愿/不需要医疗介入的人

### User Pain Points
- 不知道自己的肠道是否“正常”
- 排便是私密行为，从未被解释过
- 市面检测要么侵入式、要么一次性、要么难以理解
- 吃了“对肠道好的产品”，但不知道有没有效果

### Hardware (Object)
**TOTO Neorest LS-W / AS-W (属于 Wellness Toilet 系列)**

### Objective（硬件存在的目的）
- 将**每天被忽略的排便行为**转化为**连续、被动、非侵入的健康数据**
- 降低肠道健康认知门槛，让“肠道状态”可视、可理解
- 建立“长期趋势”而非一次性判断

### Collected Data
- 粪便形态（Bristol 1–7）
- 颜色
- 排便频率
- 排便量（估算）

### Interpreted Indicators
- Gut Health Score
- 排便节律稳定性
- 潜在水分/膳食纤维不足信号

### Link to Danone Products
- Activia / Alpro / 肠道健康相关乳制品与植物基产品
- 数据用于解释：
  - 为什么需要益生菌
  - 为什么“每天吃”比“偶尔吃”重要

### Core Message
> 健康的第一步，不是检测一次，而是每天被理解。

## 场景 2｜Physical & Recovery Performance（运动与恢复）

### Target User
- 运动爱好者
- 高压工作人群
- 容易疲劳、抽筋、恢复慢的人

### User Pain Points
- 运动后才知道自己累过头
- 口渴≠需要补什么，说不清
- 补水、补电解质完全靠经验或感觉
- 市面运动饮料“一刀切”

### Hardware (Object)
**AbsolutSweat P1 智能汗液分析系统**

### Objective（硬件存在的目的）
- 捕捉**运动中实时流失的数据**，而不是事后猜测
- 将“看不见的流汗损耗”转化为“可量化的补给依据”
- 支持个性化水合与能量补给决策

### Collected Data
- 钠离子（Na⁺）
- 钾离子（K⁺）
- 汗液流速
- 皮肤温度
- 汗液葡萄糖

### Interpreted Indicators
- Hydration ID（水合类型）
- 电解质流失等级
- 疲劳耐受度
- 脱水风险

### Link to Danone Products
- Danone 电解质饮品 / 功能性饮用水
- 根据：
  - 盐流失型
  - 高能耗型
  - 快速脱水型
- 解释“为什么你需要这一种，而不是那一种”

### Core Message
> 你不是不自律，只是一直在错误地补给。

## 场景 3｜Clinical Nutrition / Tube Feeding（管饲营养 · 新增）

### Target User
- 术后/康复期患者（家属视角）
- 老年营养支持人群
- 医护人员（辅助决策）

### User Pain Points
- 吃不下 ≠ 营养够
- 管饲后不知道身体是否真正吸收
- 家属无法判断恢复是否“在正轨上”
- 营养产品看起来都一样，无法比较

### Hardware (Object)
**Clinical Nutrition Monitoring Station**
- 医疗级 BIA 体成分分析
- 连续血糖监测（CGM，展示级）
- 基础生命体征与能耗估算模块

### Objective（硬件存在的目的）
- 验证“这份营养是否真的支持恢复”
- 将**不可见的吸收与代谢过程**转化为可追踪指标
- 降低管饲营养的决策焦虑（对家属 & 护理端）

### Collected Data
- 体重趋势
- 骨骼肌量变化
- 体水分分布（ICW / ECW）
- 血糖稳定性（管饲前后）
- 静息能量消耗

### Interpreted Indicators
- Nutrition Adequacy Score（营养达标度）
- Feeding Tolerance Index（喂养耐受性）
- Recovery Readiness（恢复准备度）

### Link to Danone Products
- **Nutricia Nutrison® 管饲全营养系列**
- 数据用于解释：
  - 为什么需要“全营养而非单一补充”
  - 为什么配方、能量密度、剂量需要个性化
  - 为什么这是“被临床验证的选择”

### Core Message
> 这不是喂进去多少，而是身体真正用上了多少。
